# Gold Module 1 — Returns of Financial Assets and Instruments

This module is the reference implementation for the reusable CFA Recall module template.

## What is implemented

- 8 micro-concepts with prerequisite edges and concept-level mastery.
- 96 deterministic, original practice variants generated from reusable templates.
- 6 formula cards and 12 flashcards.
- Module-specific Diagnostic, Adaptive Practice, Weakness Only, Formula Sprint and 10-minute modes.
- A 34-question timed Module Exam with deferred correction.
- 7/30-day accuracy, speed, coverage, due count, open Error Book count, concept mastery and confusion signals.
- Strict `MASTERED` status requiring weighted mastery, a minimum concept floor, minimum exposures and 30-day accuracy.

## Public-repository content policy

The public repository stores only original learning content and metadata supplied by the user. It does **not** store CFA Institute course text or proprietary practice questions.

The user-supplied inventory for this module is recorded only as metadata:

- 34 total source questions
- 7 Practice Pack questions included in that source inventory

The current concept taxonomy is deliberately labeled `provisional-original-study-taxonomy`; it is not represented as an official reproduction of CFA Institute Learning Outcomes.

## Reusable template

The intended duplication model for future modules is:

```text
Topic
└── Learning Module
    ├── concepts + prerequisites
    ├── formulas
    ├── flashcards
    ├── generated/original practice templates
    ├── adaptive sessions
    ├── module exam
    └── mastery policy
```

Once this reference module is accepted, the same engine can be instantiated for the remaining 101 Level I 2027 modules.
